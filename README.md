# ResumeBuilder

A simple and interactive Resume Builder web application built using **HTML**, **CSS**, and **JavaScript**. This tool allows users to input their personal and professional details, and generates a clean, formatted resume that can be downloaded or printed.

---

## 🚀 Features

- Live preview of the resume as you type
- Sections for personal details, education, experience, skills, and projects
- Easy-to-use form interface
- Printable and downloadable in a professional layout
- Fully responsive design for desktop and mobile

---

## 💻 Technologies Used

- **HTML** – Structure and layout
- **CSS** – Styling and responsiveness
- **JavaScript** – Dynamic form handling and DOM manipulation
